# Thehrav Within Space

*A little space to explore yourself.*

A mobile-first web app by Thehrav Within, bringing together psychology, creativity, play and reflection.

## Built with

- Next.js (App Router), React, TypeScript
- Tailwind CSS
- Supabase (accounts and anonymous usage counts) — added in Stage 3
- Hosted on Vercel

## Build stages

1. Requirements and architecture ✅
2. Project setup, design system, welcome screen, home and five sections ✅
3. Sign-up and verification
4. First five experiences: Pick a Card, What's Your Mood?, A Little Brain Play, A Question for You, My Little Shelf
5. Admin dashboard
6. Testing (function, privacy, security, mobile)
7. Launch

## Privacy principles

- Personal journal entries, moods and reflections stay on the user's own device.
- Nothing personal is sent to AI or outside services.
- Analytics are anonymous and aggregated; no personal content or contact details appear in them.
- No diagnoses, scores, streaks or pressure to return.

## Running locally (optional)

```bash
npm install
npm run dev
```
